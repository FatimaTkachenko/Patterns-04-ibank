# Интернет-банк (тестовый режим)

[![Build and Test](https://github.com/FatimaTkachenko/Patterns-04-ibank/actions/workflows/build.yml/badge.svg)](https://github.com/FatimaTkachenko/Patterns-04-ibank/actions/workflows/build.yml)

Автотесты входа в интернет-банк с созданием пользователей через API.

## Используемые технологии
- Java 11
- Selenide 6.16.0
- REST-assured 5.5.0
- Gson 2.10.1
- Faker
- Lombok
- JUnit 5

## Временные затраты
- Ручное тестирование: 30 минут  
- Автоматизация: 90 минут
